# Apple Financial Analysis Project


## Project Overview

This project analyzes Apple's financial performance from 2021 to 2024 using Python and financial statement data.

The objective is to evaluate:

- Revenue growth
- Profitability
- Cash flow performance
- Financial risk


## Business Questions

This project answers:

1. How did Apple's revenue change from 2021 to 2024?

2. Did profitability improve or decline?

3. Is Apple generating strong operating cash flow?

4. What is the trend of financial leverage?


## Dataset

Source:

Apple annual financial reports.

Financial statements analyzed:

- Income Statement
- Balance Sheet
- Cash Flow Statement


Period:

2021 - 2024


## Tools

Python

Libraries:

- Pandas
- Matplotlib
- ReportLab

Environment:

- Jupyter Notebook
- GitHub


## Analysis Process


### 1. Data Loading

Imported:

- Income Statement
- Balance Sheet
- Cash Flow Statement


### 2. Financial Metrics Calculation

Calculated:

- Revenue Growth
- Gross Margin
- Net Income Growth
- Debt Ratio


### 3. Financial Visualization

Generated:

- Revenue Trend
- Gross Margin Trend
- Net Income Trend
- Free Cash Flow Trend


### 4. Automated Insights

Generated automatic financial interpretations based on calculated metrics.


### 5. Automated Report Generation

Created PDF financial report using ReportLab.


## Key Findings

- Apple's revenue remained relatively stable between 2021 and 2024.

- Gross margin remained at a high level.

- Free cash flow stayed positive.

- Debt ratio indicated a relatively leveraged capital structure.
